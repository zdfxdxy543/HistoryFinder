HistoryFinder 文字载体延迟生成与渐进损伤设计方案
==================================================

一、目标

1. 世界生成时确定作品身份、作者、文体、主题、生成种子和原本/抄本关系。
2. 玩家首次正式阅读时才物化长篇正文；当前版本先使用规则生成器。
3. 玩家先发现抄本时，系统必须先在后台物化根原本，再由根原本派生抄本。
4. 同一原本的普通抄本共享绝大部分正文，只允许可追踪的漏行、异文、地方释词、边注和校勘记。
5. 物理损伤只能在正文和抄本生成完成后施加，不得参与正文创作。
6. 损伤随耐久度逐步加深；缺损位置固定、单调增加，重复阅读不得重新随机。
7. 所有生成结果、抄写差异、分页和损伤地图必须进入世界存档。
8. 玩家只能看到当前载体可读文字；隐藏的标准正文不得通过玩家安全接口泄漏。

二、三层内容模型

1. 作品层：原作者写下的标准正文和作品规划。
2. 版本层：某一抄本实际抄下的正文，以及相对母本的传抄差异。
3. 载体层：分页、材质、当前耐久度和物理损伤共同决定的可见文字。

处理顺序固定为：

作品规划 -> 根原本正文 -> 抄本正文 -> 载体分页 -> 物理损伤 -> 玩家阅读结果

三、数据结构

Evidence.content_data 中保存以下字段：

text_plan
  format_version             计划格式版本
  work_id                    同一作品家族的稳定标识
  root_evidence_id           根原本证物 ID
  parent_evidence_id         直接母本证物 ID，可为空
  subtype                    文书/作品子类型
  generation_seed            稳定生成种子
  generation_variant         碰撞重试序号
  copy_index                 抄本序号，可为空
  materialization_status     planned / generating / ready / failed
  generator_kind             rules，未来可扩展为 local_llm
  prompt_version             未来模型提示词版本

written_content
  format_version
  language_code
  language_name
  passages
    section_id               本载体稳定段落 ID
    source_section_id        对应母本段落 ID
    kind                     heading / body / closing / marginalia 等
    text                     本载体实际写下的文字
  transmission_variants      漏行、异文、边注和地方改写记录

text_layout
  page_count
  pages
    page_index
    section_spans            段落在页内的字符范围

damage_state
  condition_checkpoint       损伤地图对应的耐久比例
  damage_seed
  lesions
    lesion_id
    damage_type
    page_index
    start / end
    severity
    activation_condition
    reversible

四、延迟物化流程

1. 世界生成阶段只为普通文书保存 text_plan，不生成 written_content。
2. 公开碑铭因题名需要一眼可见，可以在世界生成时直接物化短正文。
3. 阅读普通原本时，规则生成器根据事件与 text_plan 生成标准正文。
4. 阅读抄本时递归查找 root_evidence_id；若根原本未物化，先物化根原本。
5. 根原本物化不会把原本加入玩家发现列表，也不会暴露原本位置。
6. 抄本使用母本文字和稳定 transmission_plan 派生，不允许独立自由创作。
7. 同一 work_id 使用生成锁；并发请求只能产生一份根正文。
8. 生成、抄本派生、分页和初始损伤必须全部成功后再原子写入存档。
9. 当前规则生成失败时返回明确错误；未来模型失败时回退到同一规则生成器。

五、抄本一致性

精校抄本保留母本 95%-99% 的正文。
普通抄本保留母本 88%-96% 的正文。
劣质抄本保留母本 75%-90% 的正文。
节录本按完整章节截取，不随机截断句子。
改编本必须建立新的派生作品 ID，不作为普通抄本处理。

允许的传抄操作包括：

1. 漏抄一行或一个短句。
2. 重复一行。
3. 替换一个地方词汇。
4. 改变标点和断句。
5. 保留异体人名。
6. 新增页边注、地方释词或校勘记。
7. 标注母本已经存在的缺损。

六、分页与渐进损伤

正文和抄本生成完成后，先按段落进行稳定分页。损伤地图只能引用已存在的页码和字符范围。

目标不可读比例使用连续曲线计算：

  target_loss = max_loss * (1 - condition_ratio)^2

耐久比例 0.85-1.00：正文完整，只显示污迹、褪色和轻微磨损。
耐久比例 0.65-0.85：少量局部模糊，约 0%-4% 不可辨。
耐久比例 0.40-0.65：连续小段缺损，约 4%-15% 不可辨。
耐久比例 0.20-0.40：页角脱落和裂口扩大，约 15%-35% 不可辨。
耐久比例 0.00-0.20：多页残缺，仅保留较大连续片段。
destroyed：载体永久无法阅读。

缺页、石块剥落和大面积烧毁只允许在较低耐久度出现。轻微风化不得直接造成整页丢失。

每件载体根据 evidence_id 和 damage_seed 建立固定损伤前沿。耐久下降时只扩大既有损伤或按固定顺序激活新损伤；不得重新选择位置。褪色和污渍可以通过修复改善，缺页、烧毁和剥落不可逆。

七、材质差异

羊皮纸：水渍晕墨、虫蛀、折痕断裂、焦边、缺页。
纸张：潮解、墨迹扩散、撕裂、粘连。
木板：开裂、腐朽、刮除、表层脱落。
石碑：风化、裂缝、剥落、后刻覆盖。
金属板：锈蚀、弯折、表面磨平。

八、阅读与比较

1. 阅读器先检查语言，再结合 damage_state 输出当前可见文字。
2. 缺损以“〔水渍模糊〕”“〔页角缺失〕”“〔中间一叶脱落〕”等连续标记显示，不使用大量方框制造乱码效果。
3. 同一载体重复阅读必须逐字一致。
4. 比较抄本时使用 source_section_id 对齐段落。
5. 另一抄本可以帮助提出复原建议，但不能修改受损载体本身。
6. 复原结果必须带来源与置信度，不能直接成为历史事实。

九、去重与内容质量

根原本需要检查全文哈希、重复句、段落 n-gram、情节/论证签名和高频套话。无关联作品不得大段复用相同正文。抄本与母本的高相似度属于预期行为，不参加普通作品去重；抄本改为检查保真率是否符合 transmission_plan。

文学正文禁止以“本书讲述”“第一章讨论”等摘要句代替实际场景、叙述和对白。理论著作必须包含具体定义、观察、论证、反例和限制。碑铭必须保存实际铭文，而不只是对铭文内容的说明。

十、兼容与迁移

1. 旧存档已经保存的 written_content 保持原样，不自动改写。
2. 旧存档缺少正文的文书迁移为 planned。
3. 无可靠母本关系的旧文书保留为独立作品，避免错误合并。
4. 新格式提升 written_content.format_version，并保留旧字段读取兼容。
5. text_plan、written_content、text_layout 和 damage_state 全部参与 World 序列化。

十一、验收条件

1. 先读抄本时根原本先被物化，但玩家不会自动发现原本。
2. 同一原本的普通抄本至少保留约 88% 的对应正文。
3. 不同抄本的差异可以定位到具体段落和传抄操作。
4. 损伤一定发生在抄本正文生成之后。
5. 耐久高于 85% 时不会缺页。
6. 耐久下降时不可读字符数单调增加，缺损位置不跳动。
7. 载体损伤不会改变作品标准正文或其他抄本。
8. 同一载体重复阅读结果完全一致。
9. 两个并发阅读请求不会生成两份不同原本。
10. 完全不启用模型时，规则生成器仍能完成全部流程。
